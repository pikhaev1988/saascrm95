# Платформа «Анализ ГИА»

**Назначение.** Веб‑сервис аналитики результатов ГИА и ВПР для образовательной организации: школа, район, министерство.

**Модель предоставления.** Доступ к личному кабинету в сети Интернет (SaaS). Установка программы на компьютеры школы не требуется.

## 1. Что делает платформа

Школа загружает протоколы ЕГЭ, ОГЭ и ВПР. Платформа:

- импортирует результаты обучающихся и заданий;
- считает показатели (средний балл, доля сдавших, успешность заданий, группы риска);
- строит аналитику по предметам, классам и тематическим блокам КИМ;
- формирует управленческие и предметные справки в Word, Excel, PDF и презентации.

Платформа не заменяет РИС ГИА, ФИС ГИА и РЦОИ. Она работает с копиями протоколов, которые школа сама выгружает и загружает в кабинет.

Лицензия на образовательную деятельность по 273‑ФЗ для такого сервиса не нужна: это аналитический инструмент, а не реализация образовательной программы.

---

## 2. Как устроен доступ

Три роли:

| Роль | Что видит |
| --- | --- |
| Школа | Только свои загрузки, своих обучающихся и свои отчёты |
| Район | Школы своего района |
| Министерство | Подведомственные районы и школы |

Вход по логину и паролю. Кабинет школы привязан к конкретной образовательной организации. Школа не видит данные другой школы.

Учётные записи создаёт правообладатель по заявке организации. Пароль пользователь может сменить в профиле.

---

## 3. Какие данные обрабатываются

Школа загружает файлы протоколов. В системе могут храниться:

- наименование и код образовательной организации;
- ФИО обучающегося, класс, идентификатор из протокола;
- предмет, дата и тип экзамена (ЕГЭ / ОГЭ / ВПР);
- баллы, отметки, успешность заданий;
- исходный файл загрузки.

Данные нужны только для расчёта аналитики и формирования отчётов для этой же организации.

## 4. Где размещена система

Сервис размещён на серверах на территории Российской Федерации (хостинг Beget). Обмен с кабинетом идёт по HTTPS.

Для улучшения формулировок аналитических текстов может использоваться сервис GigaChat (ПАО Сбербанк, РФ). В запрос уходят агрегированные показатели (предмет, средний балл, доли, черновик выводов), а не файлы протоколов и не ФИО обучающихся.
