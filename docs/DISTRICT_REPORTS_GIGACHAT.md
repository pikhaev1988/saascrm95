# Промпты GigaChat для районных отчётов

Все отчёты используют **системный промпт** в зависимости от типа экзамена:

- **ЕГЭ** — модуль из `users/gigachat_analysis.py` (`EGE_SYSTEM_PROMPT`): шкала 0–100, вторая часть, аналитические компетенции.
- **ОГЭ** — `OGE_SYSTEM_PROMPT`: пятибалльная шкала, базовые умения, формат КИМ.

**Пользовательский промпт** собирается в `users/district_gigachat_analysis.py` (`_build_district_user_prompt`).  
Вызов: `enrich_district_report_with_ai(report_kind=..., stats=..., draft_...)`.

Ожидаемый ответ модели — JSON:

```json
{
  "insights": ["..."],
  "recommendations": ["..."],
  "conclusions": ["..."],
  "executive_summary": ["..."]
}
```

---

## 1. Свод результатов ГИА по району (`gia_summary`, `doc=gia-summary`)

Для **ЕГЭ** и **ОГЭ** используется отдельный утверждённый промпт министерства (`DISTRICT_EGE_GIA_SUMMARY_PROMPT_BODY` / `DISTRICT_OGE_GIA_SUMMARY_PROMPT_BODY`) с подстановкой таблиц (`format_district_ege_gia_summary_tables` / `format_district_oge_gia_summary_tables`) и расширенной схемой ответа (`DISTRICT_GIA_SUMMARY_JSON_SCHEMA`): 8 разделов отчёта, пять главных проблем и сильных сторон, прогноз, план действий. Тексты отчёта — только на русском.

**ОГЭ:** пятибалльная шкала (2–5), порог сдачи ≥3, качество ≥4; без терминологии ЕГЭ (0–100 баллов).

**ЕГЭ:** шкала 0–100, вторая часть, профильные показатели.

**Запасной краткий режим** (если нет `payload` или API выключен): `DISTRICT_REPORT_TASK_INSTRUCTIONS["gia_summary"]`.

**Статистика в таблицах:** год, участники, число школ, средний показатель, успеваемость, качество, республика, дельта, распределение, предметы, школы, слабые предметы.

---

## 2. Информационно-статистический отчёт (`info_stat`, `doc=info-stat`)

Для **ЕГЭ** и **ОГЭ** — утверждённый промпт государственной аналитической системы (`_district_info_stat_prompt_body` + `DISTRICT_INFO_STAT_JSON_SCHEMA`) с таблицами из `_build_district_gia_summary_payload`. Десять разделов отчёта, предупреждения о срочном вмешательстве, управленческие решения с приоритетом и сроками, заключение с оценкой системы образования. Тексты — только на русском, без технических структур.

**Запасной режим:** `DISTRICT_REPORT_TASK_INSTRUCTIONS["info_stat"]`.

---

## 3. Аналитическая справка (`analytic_note`, `doc=analysis-note`)

Для **ЕГЭ** и **ОГЭ** — отдельные утверждённые промпты (`DISTRICT_EGE_ANALYTIC_NOTE_PROMPT_BODY` / `DISTRICT_OGE_ANALYTIC_NOTE_PROMPT_BODY` + `DISTRICT_ANALYTIC_NOTE_JSON_SCHEMA`) с таблицами и динамикой по годам. ЕГЭ: раздел «Управленческие решения», шкала 0–100. ОГЭ: «Управленческие рекомендации», пятибалльная шкала. Тексты — только на русском, без технических структур.

**Запасной режим:** `DISTRICT_REPORT_TASK_INSTRUCTIONS["analytic_note"]`.

---

## 4. Предметная справка (`subject_note`, `doc=subject-notes`)

**Задача (user):**

Сформируй предметную справку по муниципалитету: интерпретация среднего балла и успеваемости по предмету, слабые задания (если переданы), различия между школами района, рекомендации предметникам и методистам. insights — диагностика; recommendations — конкретные меры подготовки; conclusions — итог для МО по предмету.

**Доп. контекст:** название предмета.

---

## 5. Сравнение школ (`school_comparison`, `doc=school-comparison`)

Для **ЕГЭ** и **ОГЭ** — отдельные промпты (`DISTRICT_EGE_SCHOOL_COMPARISON_PROMPT_BODY` / `DISTRICT_OGE_SCHOOL_COMPARISON_PROMPT_BODY`) и схемы JSON. ЕГЭ — 10 разделов; ОГЭ — 12 разделов (общие показатели, первоочередные меры отдельно, рекомендации по аудиториям). Таблица сравнения ОО с категориями и динамикой. Тексты — только на русском, без технических структур.

**Запасной режим:** `DISTRICT_REPORT_TASK_INSTRUCTIONS["school_comparison"]`.

---

## 6. Отчёт МО (`mo_report`, `doc=mo-report`)

**Задача (user):**

Сформируй выводы для муниципального методического объединения: эффективность подготовки по циклу МО, проблемные предметы в зоне ответственности МО, динамика, рекомендации для заседания МО и отдела образования. Учитывай, что данные агрегированы по всем школам района по профилю МО.

**Доп. контекст:** название МО (математика, русский, естественно-научный и т.д.).

---

## 7. Управленческий отчёт (`management`, `doc=management-report`)

- **ЕГЭ** — `DISTRICT_EGE_MANAGEMENT_PROMPT_BODY` + `DISTRICT_EGE_MANAGEMENT_JSON_SCHEMA`: 11 разделов (включая сравнительный анализ с регионом и динамикой), рекомендации по пяти аудиториям, прогноз и контроль.
- **ОГЭ** — `DISTRICT_OGE_MANAGEMENT_PROMPT_BODY` + `DISTRICT_OGE_MANAGEMENT_JSON_SCHEMA`: 10 разделов, план мероприятий, рекомендации по четырём аудиториям.

Данные: свод муниципалитета, школы риска, слабые задания КИМ, динамика; для ЕГЭ — сравнение со среднерегиональным баллом и лидеры по ОО.

---

## Общие правила (в каждый user-промпт)

- Контекст: муниципальный уровень — агрегация по всем ОО района.
- Опираться только на переданную статистику; не выдумывать цифры и школы.
- Стиль: официальный, управленческий, русский язык.
- Черновики из кода можно улучшать, факты сохранять.

## Переменные окружения

- `GIGACHAT_AUTH_KEY`, `GIGACHAT_MODEL`, `GIGACHAT_SCOPE`, `GIGACHAT_VERIFY_SSL_CERTS`
- Включение анализа: флаг из `users.gigachat_client._analysis_enabled()` (см. `.env.example`)
